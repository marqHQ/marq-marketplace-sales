# Three-bullet call summary

1. Read the pasted note completely. Treat it as the only source; do not infer anything the note does not say.
2. Produce exactly three bullets: outcome, open question, next step. If the note lacks one, write "not discussed" for that bullet.
3. Never write to the CRM. Offer the bullets for the rep to paste. See [style rules](references/style.md).
